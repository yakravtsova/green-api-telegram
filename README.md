# GREEN-API Telegram Chat

Тестовое задание GREEN-API (Frontend React): веб-чат для отправки и приёма текстовых сообщений Telegram через HTTP API GREEN-API.

## Запуск

```bash
npm install
npm run dev
```

## Скрипты

- `npm run dev` — dev-сервер
- `npm run build` — проверка типов и сборка
- `npm run test` — unit-тесты (Vitest)
- `npm run lint` — ESLint
- `npm run format` — Prettier
